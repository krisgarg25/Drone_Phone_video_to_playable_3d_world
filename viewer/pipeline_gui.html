      05 · Download evidence
      
          
        
          
        Only server-reported files under this scene’s /work/ directory are linked. No fabricated report or aggregate score.
        
        
        
      
        
      
        
        
        
          
        Six criteria. Separate evidence.
        Weights, not scores
        
          
        
            
        Independent accuracy target
        ≤ 1 m
        Measured against held-out reference
        
            
        End-to-end processing target
        < 15 min
        For a genuine 10 min input video
        
          
        
          
        Unknown means evidence has not been supplied or verified. Prepared, aligned and evaluated are workflow states, not passes. There is no overall score.
        
          
        
        
        
        
        
          
        GPS fit ≠ independent accuracy
        
          
        
          
        
            Independent checkpoints: what Evaluate reads
            
        Evaluate optionally reads work/<scene>/survey/checkpoints.json. Checkpoints must be held out of alignment and pair independently surveyed references with corresponding reconstructed points, in the coordinate frames required by the evaluator.
        
            
        Required JSON fields: independent: true, alignment: "none", and coordinate_frame copied exactly from this scene’s georeference.json, including its origin. checkpoints must contain 1–10,000 objects, each with reconstructed and reference three-number coordinate arrays in that shared ENU metre frame. No best-fit alignment is performed on these pairs.
        
            
        GPS samples or alignment inliers are not independent checkpoints. Without a validated checkpoint file, accuracy remains unknown. This UI does not create reference measurements.
        
          
        
        
        
        
        
          
        Evidence sources & limitations
        
          
          
          
          Source: the scene’s survey API response and linked on-disk artifacts. Expand each criterion for the server’s measurements, sources and warnings. Runtime inherited from existing logs is unverified unless a complete, declared-hardware benchmark is supplied.
