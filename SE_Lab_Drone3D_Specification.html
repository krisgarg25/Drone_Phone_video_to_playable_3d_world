1. Software Requirements Specification (SRS) IEEE-830 Format

1.1 Project Summary & Work Done

The objective of this project is to convert monocular video recorded from a drone or handheld smartphone into an interactive, physically walkable 3D environment inside a web browser. The core work done is summarized below:

  • Video Ingestion & Keyframing: Reads video (.mp4/.mov) and drops motion-blurred frames using Laplacian edge variance scoring to retain sharp photos with ≥70% overlap.
  • Camera Tracking (SfM): Integrates COLMAP bundle adjustment to solve 6-DoF camera trajectories and sparse point landmarks with automated rescue ladders.
  • 3D Radiance Training: Trains 3D Gaussian Splats (3DGS) on a consumer 6GB laptop GPU under an active 5.8GB VRAM cap with checkpoint backups.
  • Metric Scaling & Ground Fit: Uses RANSAC ground plane fitting and physical flight speed/height anchors to scale arbitrary units into real meters (+Z upright).
  • Physics Collision Meshing: Builds 0.35m voxel boundary colliders and selects the optimal walkable ground surface (mesh vs. heightfield).
  • Automated 11-Rule Quality Gate: Tests ground orientation, player spawn clearance, and boundaries with zero tolerance for inverted floors.
  • Autopilot Robot Walk Test: Simulates a character walking 10 meters headless, verifying 0 fall events before approving scene release.
  • Browser Delivery (WebGL): Packages assets into a lightweight PlayCanvas HTML5 viewer running smoothly at 60 FPS on standard browsers.

3.1 Class Responsibilities & Collaboration Dictionary

Class Name Core Role & Implementation Responsibility Direct Collaborators
PipelineController Master orchestrator. Controls stage dependencies, checks resumability from logs, and catches hardware aborts. Orchestrates all 5 worker classes.
KeyframeSelector Pre-processing module. Computes Laplacian variance blur scores and decimates frames while maintaining ≥70% visual overlap. Outputs keyframe directory to COLMAPRunner.
COLMAPRunner Structure-from-Motion engine. Matches feature points, runs bundle adjustment, and triggers rescue ladders if camera solving diverges. Delivers camera poses to SplatTrainer.

SpatialFramer & Collider Geometry engine. Fits the ground plane, applies speed/height anchors for metric scaling, and extrudes solid voxel collision shells. Feeds collision mesh to QualityGate.
QualityGate & Autopilot Verification test harness. Tests 11 assertions and drives a headless kinematic capsule character 10m to prove walkability. Authorizes output release to PlayCanvasViewerBridge.

4.4 Step-by-Step Pipeline Execution Summary

Stage Internal Processing Actions Observable User Output
1. Preflight Scans video frames for motion blur and detects camera focal lengths. Console logs: "Inspecting video... Presets tuned for room capture."
2. SfM Solve Extracts feature points and tracks 3D camera angles. Automatic rescue ladder kicks in if solving diverges. Console logs: "COLMAP registered 428/430 frames (99.5% success)."
3. 3D Splatting Trains 350k Gaussian light ellipsoids, regularly checkpointing progress to prevent data loss. Progress reaches 12,000 steps; VRAM consumption stays under 5.8 GB.
4. Floor & Walls Fits ground plane to true meters and extrudes collision barriers for obstacles and boundaries. Generates solid physics mesh (collision.obj) and floor elevations.
5. Robot Walk Drives a headless avatar 10 meters through the space to ensure no falls through the floor occur. Console logs: "Autopilot walk: 10.4m completed, 0 falls. Gate Passed!"
6. Web 3D Launches an in-browser WebGL environment with keyboard navigation (WASD/arrows). Automatically opens http://localhost:8137 at a smooth 60 FPS.
